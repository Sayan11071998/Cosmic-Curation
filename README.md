# 🚀 Cosmic Curation – A Space Battle Adventure! 🌌

**Cosmic Curation** is an exhilarating Unity project where you control a spaceship drifting through space, dodging enemy fire, and engaging in intense battles against hostile ships. With exciting power-ups, stunning visual effects, and immersive audio, this game delivers a thrilling arcade-style space adventure!

## 🌟 Game Features:

### ✨ Dynamic Movement:
- Steer your spaceship in any direction and rotate seamlessly for smooth navigation.
### 🔫 Intense Combat:
- Fire bullets to take down enemy spaceships while dodging their counterattacks.
### ⚡ Diverse Power-ups:
- **🚀 Double Turret:** Shoot two bullets at a time.
- **🔥 Rapid Fire:** Unleash a barrage of bullets.
- **🛡️ Shield:** Activate a protective barrier to block enemy attacks.  
*All power-ups are collectible from the game world, built with Scriptable Objects, and include a timer for a temporary boost.*
### 👾 Relentless Enemies:
- Face foes that crash into you, shoot relentlessly, and adapt their movement when nearby.
### 🎆 Visual & Audio Effects:
- Experience dynamic explosions and impactful visual effects paired with engaging sound design.
### 🔄 Optimized Object Management:
- Implement the Object Pooling design pattern to recycle enemies, bullets, power-ups, and VFX, saving memory and boosting overall performance.
### 🛠️ Centralized Game Services:
- Use the Service Locator pattern as a Generic Mono Singleton to centralize control over all game services (audio, visual, and gameplay), ensuring a maintainable and scalable codebase.
### 🎵 Immersive Sound:
- Leverage Scriptable Objects for sound effects that deepen the gameplay experience.

## 💡 Key Learnings & Technologies:
- **🧩 Object Pooling:** Enhanced performance by reusing objects like bullets, enemies, and effects without constant instantiation.
- **🚦 Service Locator Pattern:** Streamlined architecture and improved code maintainability by centralizing game services.
- **📐 Design Patterns & Architecture:** Reinforced the importance of modular, scalable code for high-performance gameplay.
